# Same and Different (grades K-2): the 12-round outline, for your approval

Written 2026-11-01. Outline only: no round text is written until you approve or edit each line. Concept approved 2026-11-01 (`NEW_GAMES_FOR_GAPS.md`, proposal 1). Each run would play 4 of these 12 rounds.

**Links (draft, yours to sign off):** NY SEL 2B Similarities and differences (direct), 2A Empathy (supporting). Portrait of a Graduate: Global Citizen (supporting). This is the first game in the catalog for 2B, which has no coverage today.

**How it plays (same engine as Sharing Circle and Helper's Choice, no new code):** a short scene read aloud with a picture. The child taps one of three picture choices. Each choice has a spoken line that explains it, so a wrong answer teaches. No reading is required, as in the other Discover games.

**Three kinds of round, four of each,** so a run always mixes them:
- **Same:** "What is the same about Ana and Ben?" (the right choice is something both have; each wrong choice is true of only one child)
- **Different:** "What is different?" (the right choice is a real difference; the wrong ones are things the two share)
- **Kind choice:** "What could Ana do?" (the right choice welcomes the difference; the wrong ones are believable but leave someone out, never mean)

**The message in every explanation:** different is okay, different can be interesting, and being the same in one way does not make anyone better. No difference is ranked or treated as a problem.

**Writing rules a test will enforce:** three picture choices per round; each wrong choice is true of one child or of both, so a child must listen to the whole scene; the right choice is not always the longest; spoken feedback on every choice; no dashes; fictional names, mixed; scenes of two to four short sentences.

**Spread checks:** same 4, different 4, kind choice 4. The right choice sits in all three picture slots (the engine shuffles them every run). The differences are everyday ones: lunch, glasses, hair, home language, games, how a birthday is celebrated, who lives at home, and how a child gets around. None is a problem to fix. No child is the "different" one every time (the new student is Sam in one round, Leo in one, and everyone else is a "friend" in the rest).

**Reading level:** none required; every round is narrated, with emoji pictures like Sharing Circle.

**Audio:** like every Discover game today, it will use the browser voice until the Ava audio pre-render is done for the Discover games. It does not depend on that work to ship.
