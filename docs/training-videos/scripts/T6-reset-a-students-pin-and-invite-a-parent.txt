# T6  Reset a student's PIN and invite a parent  (page: teacher-classroom.html)
# Record as: a sales-demo teacher. Use a demo student and an example.com parent address.
[SCREEN] The Students tab.
[SAY] Two quick jobs you'll do often. Helping a student who forgot their P-I-N, and inviting a parent to follow along.
[SCREEN] Select Reset PIN on a student row.
[SAY] On the Students tab, find the student, and select Reset P-I-N. Type a new one, four to six digits, and save. Tell the student, and ask them to keep it somewhere private.
[SAY] A tip. Five wrong tries in a row will lock a username for about fifteen minutes. If a student says they're locked out, give it a little time, or reset the P-I-N to a fresh one.
[SCREEN] Select Invite Parent.
[SAY] To invite a parent, select Invite Parent on that student's row. Enter the parent's email, and add a short message if you'd like. The invitation works for fourteen days.
[SCREEN] The Pending Parent Invitations table.
[SAY] Pending invitations are listed below the students. If you sent one to the wrong address, select Revoke. If it expires, send a new one.
[SAY] Parents only see whether each lesson is done, and the lesson resources. They don't see quiz answers or what their child wrote.
